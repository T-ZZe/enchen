# EnchantLimit

Plugin Paper 26.3 : `/enchantement` (OP) ouvre une interface pour limiter les niveaux d'enchantement par equipement.

- Clic gauche sur un livre : baisse la limite (boucle : 4 -> 3 -> 2 -> 1 -> 0 (interdit) -> 4)
- Clic droit : augmente la limite
- Shift + clic : remet la valeur vanilla
- Les limites s'appliquent a la table d'enchantement, l'enclume, la forge (amelioration diamant -> netherite)
  et un controle regulier de l'inventaire des joueurs.

Compilation : onglet Actions de GitHub -> artefact `EnchantLimit`.
